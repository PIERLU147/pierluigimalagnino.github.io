# Sito Portfolio – Pierluigi Malagnino

Sito web statico multipagina, bilingue (Italiano / Inglese), con modalità chiara/scura automatica e modulo di contatto funzionante senza backend.

## Struttura dei file
- `index.html`: Pagina iniziale ("Chi sono") con bottoni rapidi per LinkedIn, download del CV e navigazione verso tutte le sezioni.
- `formazione.html`: Percorso universitario, diploma tecnico, corsi Cisco e certificazione Cambridge B2.
- `esperienze.html`: Esperienze lavorative valorizzate in ottica IT Support / Customer Care.
- `competenze.html`: Competenze tecniche suddivise per area e soft skills.
- `interessi.html`: Interessi personali (HomeLab, pallavolo, videogiochi, fiction).
- `contatti.html`: Modulo di contatto che inoltra automaticamente le email a `pierluigimalagninoo@gmail.com`.
- `style.css` & `script.js`: Grafica minimale, tema chiaro/scuro, traduzione IT/EN sincronizzata tra le pagine e invio form.
- `CV-Pierluigi-Malagnino.pdf`: Curriculum vitae aggiornato pronto per il download.

## Come pubblicarlo su GitHub Pages
1. Estrai tutti i file da questo archivio `.zip` in una cartella sul tuo computer.
2. Vai sul tuo repository GitHub (`tuousername.github.io`), clicca su **Add file → Upload files**.
3. Trascina **tutti i file** estratti (assicurati che `index.html` sia nella cartella principale, non dentro una sottocartella) e clicca **Commit changes**.
4. Dopo 1-2 minuti il sito sarà online.

## Attivazione del modulo Contatti (solo la prima volta)
Il form usa **FormSubmit** per inoltrarti le email senza bisogno di un server:
1. Appena il sito è online, vai nella pagina **Contatti** e inviati un messaggio di prova compilando i campi.
2. Controlla la tua casella `pierluigimalagninoo@gmail.com`: riceverai un'email da FormSubmit con un link **Activate Form**.
3. Clicca su quel link una sola volta. Da quel momento in poi, ogni messaggio inviato dal sito arriverà direttamente nella tua casella email.
