# Sito Portfolio – Pierluigi Malagnino

Sito web statico multipagina, bilingue (Italiano / Inglese), con download dinamico del CV nella lingua selezionata (IT o EN), modalità chiara/scura automatica e modulo di contatto funzionante senza backend.

## File aggiornati per il download dinamico del CV
Se hai già caricato la prima versione del sito su GitHub, ti basta caricare/sostituire questi 5 file:
- `index.html`
- `contatti.html`
- `script.js`
- `CV-Pierluigi-Malagnino-IT.pdf` (Curriculum in Italiano con link al portfolio)
- `CV-Pierluigi-Malagnino-EN.pdf` (Curriculum in Inglese con link al portfolio)
